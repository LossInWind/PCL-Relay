# PCL Relay 2.5.13

本版统一发布 macOS 应用和 Linux x86_64 / aarch64 安装包；所有资产来自同一提交，附带 SHA-256 校验文件。应用构建标识与组件版本分别展示。

## 改进

- 路由页统一设备列表、检查状态和升级目标计数；设备在线不再等同于模型可用。
- Agent 选择串行保存并回读确认；连续操作保留最后选择。目录收缩不会静默移除已配置模型，缺失定义会阻止不完整写入。
- 刷新独立等待各区域完成，保留并标记历史结果；刷新不应用路由、不重启模型服务。
- 模型页合并重复入口，支持搜索、调用示例和能力实测确认；门户显示持续操作反馈。
- 设置窗口支持关闭后保留菜单栏、再次打开唤出窗口；跟随系统外观。
- HTTP 错误保留经过脱敏的上游原因，不再只显示无上下文的状态码。

## 验证与边界

33 项 Swift、208 项 Python 测试通过。本机官方 GPT 请求通过；DeepSeek Pro、DeepSeek Flash、GLM 的流式响应、上下文压缩、工具调用与继续对话通过。OpenCodex 仍固定为 2.46.0，协议实现和运行时版本未改变。

发布时 Kimi-K3 上游返回 503 / model_not_found（pcl 分组无可用通道）。这不是本版引入的问题；配置会保留，目录缺失会明确提示，不能将其计为当前可用。详见 [本机验收记录](../UI-RELIABILITY-ACCEPTANCE.md)。

本版不修改登录凭据、历史会话、项目模型设置或 SSH/Clash/文件挂载。安装包可用不代表设备后台已运行新版；设备应通过现有更新流程分别验证。不要为更新界面强制重启正在承载请求的模型服务。
