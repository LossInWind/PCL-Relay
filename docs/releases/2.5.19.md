# PCL Relay 2.5.19

Adds passive, metadata-only Chat stream diagnostics to the Relay gateway and
server details. Reports waiting, incomplete streams, transport errors and observed
protocol termination without equating protocol termination with task success.

No changes to upstream OpenCodex, request/response bytes, retries, authentication,
history, SSH or proxy configuration. Diagnostics retain no prompt or response text.

The macOS GUI is rebuilt from this release. Platform packages reuse the verified
2.5.18 embedded OpenCodex runtimes unchanged; Relay Python sources are refreshed.
Gateway diagnostics require safe activation of the updated gateway process.
Installing a package alone does not update an already-running process.
