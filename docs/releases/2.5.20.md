# PCL Relay 2.5.20

Includes the metadata-only Chat stream diagnostics from 2.5.19 and makes their
read-only panel accessible in the current simplified Routing page. The legacy
Network page is not the active UI. Inspection is explicit, does not call models,
and does not restart services. Old gateways are labeled as lacking diagnostics.

No OpenCodex core changes. No modifications to credentials, history, SSH, proxies
or model selection. Existing model processes remain untouched during installation.
Running gateways need a safe activation window for the new diagnostic fields.

The GUI is rebuilt. Embedded OpenCodex and Python runtimes are reused byte-for-byte
from verified release assets; platform Relay sources are updated to this version.
